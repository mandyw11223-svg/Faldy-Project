# Petualangan Lebah

Game edukasi interaktif tentang penyerbukan bunga.

## Mainkan

Setelah workflow GitHub Pages selesai, game dapat dibuka di:

<https://mandyw11223-svg.github.io/Faldy-Project/>

## Jalankan secara lokal

Buka folder `petualangan-lebah` menggunakan server web lokal, misalnya ekstensi Live Server di VS Code, lalu buka `index.html`.

File utama dan aset game berada di `petualangan-lebah/`. Pengaturan suara ada di `petualangan-lebah/voice.js`; suara rekaman bersifat opsional karena browser akan menggunakan text-to-speech saat file audio tidak tersedia.

GitHub Actions menerbitkan folder tersebut ke GitHub Pages setiap ada push ke branch `main` atau branch publikasi saat ini.
