CARA MENGGANTI SUARA
====================
1. Rekam / buat suara kamu, simpan sebagai .mp3 (atau .wav / .ogg).
2. Taruh filenya di folder ini (assets/audio/).
3. Nama file harus sama dengan yang tertulis di voice.js
   (atau ubah nama file di voice.js, bagian  file:'...').
4. Kalau file tidak ada, game otomatis memakai suara komputer (bahasa Indonesia).
